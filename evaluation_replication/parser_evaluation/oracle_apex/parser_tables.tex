\subsubsection{GUI-Model Parser Coverage}
\label{subsubsec:parser-gui-results}

For Oracle APEX, the parser achieves 85.1\% screen coverage, 93.8\% button and 93.8\% label coverage, 84.6\% button action-type coverage, and 86.2\% form coverage on the five evaluated SQL exports. Bound entity coverage is 100.0\%: declared report tables and form-process tables are resolved to B-UML class references. Navigation coverage is 0.0\%, since the current parser does not construct navigation actions. The 11 omitted screens are excluded by the page-ID and page-name filtering rules, which skip pages such as home, global, and login pages; App~1 also loses its Basic Collections page because its ID is 1. Buttons and forms on omitted pages are consequently absent from B-UML. A primary form submit control is represented by \texttt{Form.submit\_label} rather than a standalone \texttt{Button}, which can reduce the number of distinct button action types retained in the model.
